# Clase 2

Ejemplo basico de Java para declarar variables `String`, asignar valores e imprimirlos en consola.

## Ejecutar desde terminal

```bash
javac Main.java
java Main
```

Salida esperada:

```text
¡Hola, mundo!
Buenos días
```

## Abrir en Visual Studio Code

Abrir esta carpeta en Visual Studio Code:

```text
clases/clase2
```

Luego abrir `Main.java` y presionar **Run**.
