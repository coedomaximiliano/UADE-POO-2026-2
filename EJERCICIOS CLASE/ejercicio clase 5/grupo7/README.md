# Ejercicio clase 5 - Grupo 7

Dominio: sistema de turnos de un consultorio medico.

## Consigna resuelta

- Un medico atiende muchos turnos.
- Cada turno es atendido por un unico medico.
- Un paciente solicita muchos turnos.
- Cada turno pertenece a un unico paciente.
- Cada turno tiene fecha, hora y estado.
- Un medico tiene especialidad.
- Un paciente tiene numero de historia clinica.

## Compilar y ejecutar

```bash
javac *.java
java Main
```

## Archivos

- `Medico.java`
- `Paciente.java`
- `Turno.java`
- `EstadoTurno.java`
- `Main.java`
- `diagrama-clases.puml`
