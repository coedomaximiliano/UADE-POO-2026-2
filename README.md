# UADE - POO

Repositorio público de la cátedra para que los alumnos suban el código de los ejercicios de clase y los trabajos prácticos.

## Organización

El repositorio tiene tres carpetas principales:

```
CLASES/
  CLASE 1 07-08/
  CLASE 2 14-08/
  CLASE 3 21-08/

EJERCICIOS CLASE/
  ejercicio clase 1/
    grupo 1/
    grupo 2/
  ejercicio clase 2/
    grupo 1/

TRABAJOS PRACTICOS/
  TP1/
    grupo 1/
    grupo 2/
  TP2/
    grupo 1/
  TPI FINAL/
    grupo 1/
```

- **`CLASES/`**: material subido por la cátedra (slides, enunciados de referencia, instaladores). Es de solo lectura, los alumnos no suben nada acá.
- **`EJERCICIOS CLASE/`**: ejercicios cortos que se resuelven durante la clase. Cada ejercicio tiene su propia carpeta (`ejercicio clase N`) y, dentro, cada grupo crea su carpeta `grupo N`.
- **`TRABAJOS PRACTICOS/`**: entregas formales de cada TP (`TP1`, `TP2`, `TP3`, `TPI FINAL`). Ya existe una carpeta `grupo N` por cada grupo (1 a 8) dentro de cada TP — no hay que crearla, solo usar la que corresponde a tu grupo.

Cada grupo tiene una única carpeta compartida por todos sus integrantes.
